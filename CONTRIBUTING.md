# Contributing

Thank you for helping improve ZT Central Manager.

1. Search existing issues before filing a new one.
2. Never post real API tokens, network IDs, member data, or identifying logs.
3. Keep changes focused and add tests for behavior changes.
4. Run `dart format --output=none --set-exit-if-changed .`, `flutter analyze`,
   and `flutter test` before submitting a pull request.
5. Describe user-visible changes in `CHANGELOG.md`.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
